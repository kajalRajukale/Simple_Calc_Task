# Modern Calculator

A responsive calculator made with HTML, CSS, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Decimal numbers and positive/negative toggle
- Clear and delete buttons
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Responsive layout
- Handles division by zero

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub named `modern-calculator`.
2. Upload `index.html` and `README.md` (or push them using Git).
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.
6. After deployment, GitHub will show the published website link in the Pages section.
